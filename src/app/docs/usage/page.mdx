# Using the Dashboard

Everything in Uptime Monitor starts from the dashboard. Here’s how to get comfortable quickly.

## Create a monitor

1. Click **Add Monitor**.
2. Choose a monitor type (Website/API or App Logger).
3. Give it a clear name, choose how often it should check in, and decide whether alerts should start right away.
4. Hit **Save**—your monitor appears instantly in the grid.

## Configure alerts

- Use **Settings → Alerts** to set workspace defaults for email, Slack, or webhooks.
- Open any monitor, tap the **bell** icon, and override the defaults when you need a different destination.
- Send yourself a test alert whenever you add a new channel.

## Keep monitors organized

- Rename monitors anytime by clicking the **edit** icon.
- Pause monitoring during maintenance windows with the **active** toggle.
- Use the search bar to filter long lists in real time.

## Understand what you’re seeing

- **Status indicators** show the latest result (Up, Warning, Down).
- Monitor cards display response times and current status.
- Edit monitors to update settings and configure alerts.

## Tips for smooth operations

- Group related monitors with consistent naming (e.g., `Storefront - Checkout API`).
- Review the dashboard at least once per week to clear out stale monitors.
- After every major release, use the **Test Alert** button to confirm signals still reach your team.

Ready to go deeper? Explore [Monitor Types](/docs/monitors) to learn more about different monitor types.
