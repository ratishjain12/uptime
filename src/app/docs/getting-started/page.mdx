# Getting Started

This guide walks through the end-to-end experience of launching Uptime Monitor for your team.

## Step 1: Sign in

1. Visit your Uptime Monitor workspace URL.
2. Choose **Continue with Google** to sign in securely.
3. On first login, a personal workspace is created automatically.

## Step 2: Create your first monitor

1. Click **Add Monitor** on the dashboard.
2. Pick a monitor type:
   - **Website/API** for public endpoints.
   - **App Logger** for application-level events.
3. Give it a descriptive name and choose how often it should check in.

## Step 3: Tell us where to alert you

1. Go to **Settings → Alerts**.
2. Add the Slack channel or email distribution list that should be notified.
3. (Optional) Add a custom webhook if you want to trigger other tooling.

## Step 4: Test everything

1. Use the **Test Alert** button on each channel to confirm delivery.
2. Check your dashboard to see monitor status updates.

## What happens next?

- Website and API monitors begin running automatically.
- App Logger monitors will start receiving data as soon as the logger package sends events.
- The dashboard shows monitor status, response times, and recent checks.

Need more detail? Browse the [Usage Guide](/docs/usage) or jump to [Alerts](/docs/alerts) to fine-tune notifications.
